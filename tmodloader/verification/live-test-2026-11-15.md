# HostPause for tModLoader: live test, 2026-11-15

Setup: Linux (Fedora, Intel Arc GPU, Mesa 26.2), tModLoader v2026.08.3.0, .NET 8.0.32.
A dedicated `tModLoader -server` on port 7790 and real tModLoader clients with full graphics
(SDL Wayland driver inside a private `kwin_wayland --virtual` compositor, so no window
appeared on the desktop). Every process had its own `-tmlsavedirectory`.

- **Host** connected to `127.0.0.1`, so tModLoader counts it as the host.
- **Guest** connected to the machine's LAN address `192.168.1.39`, so it is a remote player.
- Clients ran without Steam through tModLoader's non-Steam path (an original vanilla
  `Terraria.exe` next to the tModLoader folder). `tests/SteamlessContinueHook` clicked past
  tModLoader's "Steam Game Server failed to Init" notice.
- `tests/HostPauseTestBot` drove the clients: created a player and joined, bound the pause
  key to F9 as a player would in Controls, set the key's "just pressed" state where the
  game reads it, walked, toggled tiles, logged world state every second and took
  screenshots from the back buffer.

## Bugs found and fixed during the run

- The client's first Hello could reach the server before the player counted as fully
  connected and was dropped, so the client never became ready. The server now pushes the
  state as soon as a player finishes joining, and the client repeats Hello until answered.
- Reading the keybind through `ModKeybind.JustPressed` throws while tModLoader rebuilds its
  trigger tables (mod reload); that disabled HostPause. Key reads are now defensive.
- tModLoader 2026.08 leaves mod keybinds unbound (the default applies only on "Reset to
  default"). HostPause now tells the host how to bind it and falls back to `/pause` and
  `/resume` in notices and captions.
- The 300 ms notice throttle swallowed "Countdown cancelled" right after a countdown tick.
  Only identical repeated notices are throttled now. Clients are also told when the console
  takes over a pause.

## Not covered

Windows and macOS; Host & Play over Steam (host identified by Steam ID); the Workshop
download flow; a physical key press and binding through the Controls menu; other GPUs;
other mods.
